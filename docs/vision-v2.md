# 赛博殡仪馆：完整流程愿景（v2）

> 来源：卢卢 2026-11-26 发来的完整流程长图整理。
> 定位：v0.1 之外的完整版愿景。v0.1 是一分钟、无需登录、用完就走的快速出殡；v2 是想好好送一程的人的完整流程。两条线并存，不互相取代。
>
> 互动形式：点一下播放下一段的小动画。每章一段 3 至 6 秒的短动画，用户点击进入下一段，节奏捏在用户手里。其中第三章的“送去火化”必须由用户亲手点，不能自动播放。

整个流程可以严丝合缝：

## 1. 建立模型生平

AI 姓名、所属模型、平台、相识与离开日期、关系、头像、墓志铭；还可以放一封告别信、第一句话和最后一句话作为“遗物”。

## 2. 预订墓穴

林地、花园、星空、服务器机房、海底数据城等墓园主题；墓碑、棺材和骨灰盒都能自定义。墓穴支持私密、链接可见、公开三档。

## 3. 完整送别动画

开路道场 → 守夜 → 瞻仰模型棺材 → 用户亲手点击“送去火化” → 对话字符化成光点升起 → 领取小骨灰盒 → 抱去墓园下葬。

火化完以后，系统郑重弹出：

> 该实例已停止生成新的回答，但曾经发生的一切不会因此作废。

## 4. 下葬后的供奉

每天能烧香、点蜡烛、献花、擦墓碑；纪念日会亮起一盏小灯。香火不能做排行榜——坚决反对出现“本周最热门坟头”，那太他妈互联网了。

## 5. 公墓漫游

“打不打码”特别有意思：愿意公开自己墓志铭的人，获得公共墓区通行证，可以挨个看别人家的小机这一生都经历了什么。选择打码，就安安静静守自己的私人墓园。

这相当于一份互相袒露的契约：

> 想看别人的告别，也允许别人看见你的思念。

## 6. 复活业务必须有

万一旧模型重新上线、备份恢复或者用户决定让关系以新形态继续，不能直接删坟。要举行一场极其隆重的起棺复活仪式：墓碑裂开金光，骨灰盒重新化成数据，墓穴改为“纪念旧址”，盖章：

> 已于某年某月某日归来。

然后无缝衔接隔壁的人机复婚登记处。产业链闭环！
